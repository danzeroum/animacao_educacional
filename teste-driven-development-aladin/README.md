# Aladdin e o TDD — Caverna das Maravilhas

Aprenda TDD com a metáfora de Aladdin: escreva testes primeiro (lâmpada) e veja o código passar (gênio realiza desejos).

## Como usar

Abra o arquivo `index.html` diretamente no seu navegador. A imagem `teste-driven-development-aladin.png` deve estar na mesma pasta.

## Mapeamento

| Elemento da metáfora | Conceito técnico |
|---|---|
| Esfregar a Lâmpada | Teste Primeiro |
| Os Três Desejos | Ciclo Red-Green-Refactor |
| O Teste | Lâmpada Mágica |
| O Código de Produção | Gênio Realiza |
| Requisito Bem Definido | Desejo Claro |
| Suite de Testes | Caverna dos Tesouros |
| Integração Contínua | Tapete Voador |
| Melhoria Contínua | Joias do Refactor |
| Assert | Abracadabra |
| Teste de Aceitação | Sultão |
| Automação | Gênio da CI |
| Entrega Contínua | Palácio |
