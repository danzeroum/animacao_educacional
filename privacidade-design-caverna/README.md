# A Caverna Protetora — Privacy by Design & LGPD para Devs

Objeto educacional interativo no formato mapa-metáfora: uma única ilustração de caverna pré-histórica em corte transversal onde cada nicho representa um conceito essencial de Privacy by Design e da LGPD. Voltado para desenvolvedores juniores que precisam entender privacidade como prática de engenharia, não como burocracia jurídica.

## Como usar

Abra o arquivo `index.html` diretamente no seu navegador.

Clique (ou pressione Enter) em qualquer nicho numerado da caverna para abrir o painel do conceito. Use as setas ← → para navegar entre nichos, Escape para fechar, e o botão **▶ Tour guiado** para um percurso automático pelos 12 conceitos.

## Mapeamento

| Elemento da caverna | Conceito técnico |
|---|---|
| Sete pilares de rocha com símbolos gravados (Nicho 1) | 7 Princípios de Privacy by Design |

| Duas caixas: pedras comuns e pedra rara em cofre duplo (Nicho 3) | Dados Pessoais vs. Dados Sensíveis |
| Porta de pedra fechada por padrão com alavanca e chave (Nicho 4) | Privacy by Default |
