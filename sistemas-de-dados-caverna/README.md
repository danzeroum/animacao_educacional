# A Caverna dos Dados — Sistemas de Uso Intensivo de Dados para Devs

Objeto educacional interativo no formato mapa-metáfora: uma única ilustração de caverna pré-histórica (estilo cartoon editorial) onde cada nicho delimitado por pilares de rocha representa um conceito essencial de sistemas de dados intensivos. Público-alvo: devs juniores que estão entrando no mundo de dados — Big Data, pipelines, qualidade e comunicação de resultados.

A faixa superior da caverna cobre os cinco pilares de **arquitetura macro** (os grandes conceitos estruturais); a faixa inferior mergulha nos sete aspectos do **ciclo de qualidade** (o que acontece com o dado desde a coleta até o insight). Ao clicar em qualquer nicho, um modal explica o conceito com metáfora, três bullets práticos, ferramentas reais e uma dica acionável — e acende os nichos relacionados na figura.

## Como usar

Abra o arquivo `index.html` diretamente no seu navegador. Nenhuma dependência externa ou servidor é necessário.

Coloque a imagem `caverna-sistemas-dados.png` na mesma pasta antes de abrir.

## Mapeamento

| Elemento da caverna | Conceito técnico |
|---|---|
| Cinco pilares de rocha com símbolos distintos | Os 5 Vs do Big Data (Volume, Velocidade, Variedade, Veracidade, Valor) |
| Linha de produção de três trogloditas em sequência | Pipeline ETL (Extract, Transform, Load) |
| Grande câmara com pedras brutas variadas | Data Lake — repositório bruto e variado |
| Caverna dividida por pilares em nichos autônomos | Microsserviços — compartimentos independentes |
| Múltiplas rotas paralelas de transporte de pedras | Resiliência e Escalabilidade Horizontal |
| Troglodita preenchendo buracos no mural de pedras | Tratamento de Dados Faltantes |
| Ancião com lupa rejeitando pedra absurdamente grande | Remoção de Anomalias (Outliers) |
| Artesão cortando pedras em formato padrão | Normalização de Dados |
| Trilha de pegadas da pedra processada até a fonte | Rastreabilidade de Origem (Data Lineage) |
| Trogloditas chegando de direções diferentes com pedras distintas | Coleta de Múltiplas Fontes |
| Sábio organizando pedras em padrões sobre mesa de argila | Modelagem e Comunicação de Resultados |
| Mural com alvo e trogloditas trazendo pedras de feedback | Feedback e Métricas SMART |
