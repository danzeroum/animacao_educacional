# CI/CD: Decolagem Contínua — Sala de Controle

Aprenda CI/CD através da metáfora de um avião: da esteira de manutenção ao voo em produção.

## Como usar

Abra o arquivo `index.html` diretamente no seu navegador. A imagem `ci-cd-aviao.png` deve estar na mesma pasta.

## Mapeamento

| Elemento da metáfora | Conceito técnico |
|---|---|
| Esteira de Montagem | Integração Contínua (CI) |
| Checklist de Voo | Pipeline |
| Hangar de Testes | Testes Automatizados |
| Torre de Controle | Orquestração |
| Pista de Decolagem | Entrega Contínua (CD) |
| Piloto Automático | Deploy Contínuo |
| Altitude de Serviço | Ambiente de Produção |
| Navegação por GPS | Monitoramento |
| Comunicação com Torre | Notificações |
| Aterrissagem Segura | Rollback |
| Manutenção Pós-Voo | Refatoração |
| Caixa Preta | Logs e Rastreamento |
