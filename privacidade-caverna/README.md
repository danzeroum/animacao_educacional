# A Caverna Protetora — Privacy by Design & LGPD para Devs

Objeto educacional interativo no formato mapa-metáfora: uma caverna pré-histórica em corte transversal onde cada nicho é um conceito de Privacy by Design ou LGPD. Voltado para devs juniores e times de produto que precisam entender privacidade como parte da arquitetura, não como conformidade de última hora.

A faixa superior apresenta a arquitetura de privacidade (os 7 Princípios de PbD, Bases Legais, classificação de dados, Privacy by Default e consentimento informado). A faixa inferior detalha os controles operacionais (inspeção preventiva, segurança ponta-a-ponta, classificação, proteção de dados sensíveis, cadeia de custódia, resposta a incidentes e auditoria contínua).

## Como usar

Abra o arquivo `index.html` diretamente no seu navegador.

Faça upload da imagem `caverna-privacidade-v1.png` na mesma pasta para ativar a visualização completa.

## Mapeamento

| Elemento da caverna                        | Conceito técnico                          |
|--------------------------------------------|-------------------------------------------|
| Sete pilares de rocha com símbolos gravados | 7 Princípios de Privacy by Design         |
| Conselho de anciãos com tábuas de símbolos | Bases Legais LGPD (Art. 7 e Art. 11)     |
| Pedras comuns vs. pedra rara em cofre duplo| Dados Pessoais vs. Dados Sensíveis        |
| Porta de pedra fechada por padrão          | Privacy by Default                        |
| Mural com tribo levantando a mão           | Transparência e Consentimento Informado   |
| Guardião com lupa na entrada               | Proatividade — Inspeção Preventiva (DPIA) |
| Corredor com muralhas contínuas e vigias   | Segurança Ponta-a-Ponta                   |
| Artesão etiquetando pedras                 | Classificação de Dados Pessoais           |
| Cofre duplo com duas chaves               | Proteção Reforçada de Dados Sensíveis     |
| Ancião lacrando pedra-prova em argila      | Cadeia de Custódia para Auditoria         |
| Grupo em alerta com papéis definidos       | Plano de Resposta a Incidente de Privacidade |
| Mural com trilha de pegadas auditada       | Auditoria e Rastreabilidade Contínua      |
