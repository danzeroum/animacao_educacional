    💡 Dica DevOps
    📖 Os três pilares da observabilidade (clique para expandir)
    • Logs, Métricas e Traces formam o triângulo de ouro da observabilidade — popularizado pelo livro Google SRE Workbook.
    • Shift-left on observability: instrumentar o código desde o início do desenvolvimento, não como pós-pensamento.
    • Correlation ID: passe um identificador único por todas as camadas — isso une logs, métricas e traces de uma mesma requisição.
    • OpenTelemetry é o padrão aberto para coletar os três tipos de dados sem lock-in de vendor.
    • A observabilidade não é só para produção: use em staging e dev para pegar problemas cedo.
