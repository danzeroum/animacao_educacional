# Animação Educacional — Objetos Interativos para Devs

Repositório de objetos educacionais interativos no formato **mapa-metáfora** para devs juniores. Cada objeto mapeia conceitos técnicos aos elementos de uma metáfora visual e animada, abrindo direto no navegador sem instalação.

## 🗺️ Atlas (página inicial)

O arquivo [`index.html`](./index.html) na raiz é o **acervo navegável** de todos os objetos: hero, explicação do formato mapa-metáfora, **busca** por tema, **filtros por trilha**, nível e duração estimada de cada mapa, e uma seção de acessibilidade. Abra-o no navegador para explorar o catálogo inteiro a partir de um só lugar. Como todo objeto, é um HTML único e autocontido (sem CDN, sem build).

## Como usar

Comece pelo [`index.html`](./index.html) na raiz para navegar o acervo. Para abrir um objeto direto, cada um é um arquivo `index.html` autocontido: navegue até a pasta do objeto desejado e abra o `index.html` no navegador — sem servidor, sem instalação.

## Como contribuir / criar um novo objeto

Veja [`CLAUDE.md`](./CLAUDE.md) para a convenção completa de nomenclatura, estrutura e padrões de acessibilidade.

> Ao adicionar um novo objeto, lembre-se de incluir uma linha neste catálogo **e** uma entrada correspondente no array `DATA` de [`index.html`](./index.html) (com `cenario`, `cor`, `nivel`, `tags` e `cat`) para que ele apareça no Atlas.
