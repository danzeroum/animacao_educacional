# A Caverna Arquitetada — Arquitetura de Software na Idade da Pedra

Objeto educacional no formato **mapa-metáfora**: uma caverna pré-histórica em corte transversal onde um troglodita sábio mostra à tribo que construir um "sistema" sempre exigiu arquitetura — só que, na Idade da Pedra, com outros nomes. Cada conceito de arquitetura de software é mapeado para um elemento rudimentar de pedra, osso e fogo. O objeto é dividido em uma camada **MACRO** (a caverna-tribo e seus setores) e uma camada **MICRO** (a parede de pinturas rupestres, o "centro de controle"). Voltado para devs juniores que querem uma visão geral acessível de arquitetura.

## Como usar

Abra o arquivo `index.html` diretamente no seu navegador — sem instalação, sem servidor. Clique em qualquer estação ou use o **Tour Guiado** para uma visita automática pelas 12 estações.

## Mapeamento

### MACRO — A Caverna-Tribo

| Elemento da caverna | Conceito técnico |
|---|---|
| 🪨 Abrigo de pedra com lajes encaixáveis | Escalabilidade (expansão modular / horizontal) |
| 🛡️ Muralha, armadilha de ossos e crachá-pedra | Segurança (autenticação e autorização) |
| 🏹 Armadilha de caça com teste e containers de argila | DevOps & CI/CD (testes automatizados, containers) |
| ☁️ Fogueira de sinais de fumaça | Cloud (recursos sob demanda, coordenação remota) |
| 🔥 Duas fogueiras idênticas | Disponibilidade & redundância (failover) |

### MICRO — A Parede de Pinturas Rupestres

| Elemento da parede | Conceito técnico |
|---|---|
| 🎨 Quatro pinturas sobrepostas | Modelo C4 (Contexto → Container → Componente → Código) |
| 👣 Pegadas, corda de nós e fogueira que muda de cor | Observabilidade (logging, tracing, monitoramento) |
| 🔨 Ferramenta remontada com pedras que encaixam | Refatoração (redução de acoplamento) |
| ⚖️ Duas pedras gravadas (músculo / clima) | Leis da arquitetura (trade-offs e contexto) |
| 🦴 Cofre de ossos com caveira e chave-pedra | Criptografia & acesso mínimo (dados sensíveis) |
| 📜 Ancião entregando tábuas de regras | Conformidade (LGPD / GDPR) |
| 💀 Monte de ferramentas quebradas | Dívida técnica |
