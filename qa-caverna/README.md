# A Caverna da Qualidade — QA e Testes na Idade da Pedra

Objeto educacional interativo no formato mapa-metáfora: uma única ilustração de caverna pré-histórica em corte transversal, dividida em 12 nichos, onde cada região ensina uma prática de Garantia e Controle de Qualidade. Destinado a devs juniores que querem entender QA além de "escrever testes" — do processo V&V ao Code Review colaborativo.

## Como usar

Abra o arquivo `index.html` diretamente no seu navegador. O arquivo `qa-caverna.png` deve estar na mesma pasta. Clique em qualquer nicho da caverna, use a legenda numerada ou inicie o tour guiado.

## Mapeamento

| Elemento da caverna | Conceito técnico |
|---|---|
| Dois trogloditas inspecionando com lupa e testando em uso real | Verificação vs. Validação |
| Mural em pirâmide com quatro camadas de pedra | Níveis de Teste (Pirâmide) |
| Artesão construindo gabarito antes de lascar a pedra | TDD — Testes Primeiro, Código Depois |
| Três trogloditas encenando Given / When / Then | BDD — Cenários de Comportamento |
| Esteira automatizada conectando todas as bancadas de teste | Pipeline de Qualidade Contínua |
| Troglodita testando uma única peça em bancada isolada | Teste de Unidade |
| Dois trogloditas conectando e testando o encaixe entre peças | Teste de Integração |
| Mecanismo completo com múltiplas peças em operação | Teste de Sistema |
| Usuário usando a ferramenta em cenário cotidiano real | Teste de Aceitação |
| Guardião com lupa inspecionando padrões defeituosos | Análise Estática (SAST) |
| Pilha de pedras não usadas e duas pedras idênticas removidas | Código Morto e Duplicado |
| Dois trogloditas revisando a peça lado a lado com lupa | Code Review Colaborativo |
