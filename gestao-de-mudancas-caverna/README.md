# A Caverna da Mudança — Gestão de Mudanças e Cultura Organizacional

Objeto educacional interativo no formato mapa-metáfora: uma caverna pré-histórica em corte transversal onde cada nicho representa um conceito fundamental de gestão de mudanças e cultura organizacional. Destinado a líderes, gestores e profissionais que precisam compreender como transformações organizacionais são iniciadas, sustentadas e ancoradas na cultura de times.

A faixa superior da caverna percorre os 5 primeiros passos do modelo de Kotter em ação — da urgência à ancoragem. A faixa inferior detalha os 7 elementos micro da cultura que determinam se a mudança sobrevive ou regride.

## Como usar

Abra o arquivo `index.html` diretamente no seu navegador. Coloque o arquivo `gestao-de-mudancas-caverna.png` na mesma pasta para que a imagem apareça.

- Passe o mouse sobre cada nicho da caverna para ver o destaque
- Clique para abrir o modal com a explicação completa do conceito
- Use o **Tour guiado** para percorrer todos os 12 conceitos em sequência automática
- Navegue por teclado: Tab entre hotspots, Enter/Espaço para abrir, Escape para fechar, setas ←→ durante o tour
