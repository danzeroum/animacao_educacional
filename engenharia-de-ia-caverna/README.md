# A Caverna Inteligente — Engenharia de IA para Devs Juniores

Objeto educacional interativo no formato mapa-metáfora: uma ilustração de caverna pré-histórica em estilo rupestre onde cada nicho é um conceito de Engenharia de IA. A interface é a própria imagem — clique nos nichos para aprender sobre viés, qualidade de dados, overfitting, privacidade e mais. Destinado a devs juniores que estão entrando no universo de ML/AI.

## Como usar

Abra o arquivo `index.html` diretamente no seu navegador.

A imagem de fundo (`engenharia-de-ia-caverna.png`) deve estar na mesma pasta que o `index.html`.

## Mapeamento

| Elemento da caverna rupestre | Conceito de Engenharia de IA |
|---|---|
| Conselho diverso examinando pedras coloridas | Viés e Ética |
| Artesã peneirando pedras com peneira de verdade | Qualidade dos Dados |
| Dois cestos separados por barreira de ossos | Treino vs. Teste |
| Ferramenta funcionando dentro e fora da caverna | Generalização |
| Quatro pilares de pedra com símbolos rupestres | IA Responsável (Transparência, Justiça, Privacidade, Responsabilidade) |
| Cesto com pedras de todas as regiões da tribo | Diversidade e Representatividade do Dataset |
| Ancião registrando pedras em tábulas de pedra | Auditoria e Governança de Dados |
| Cofre vedado com marca pessoal e chave dupla | Privacidade e LGPD/GDPR |
| Jovem memorizando cada detalhe das pedras | Overfitting — Memorização Excessiva |
| Vara reta que não alcança nenhum alvo | Underfitting — Simplificação Excessiva |
| Pedra com risco invisível enganando o oráculo | Ataques Adversários |
| Ancião revisando a decisão do oráculo | Supervisão Humana em Aplicações Críticas |
