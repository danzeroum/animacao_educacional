# Arquitetura C4 como Planeta Terra — Caverna

Explore a arquitetura C4 através da metáfora do planeta Terra: do núcleo ao espaço, cada camada representa um nível de abstração.

## Como usar

Abra o arquivo `index.html` diretamente no seu navegador. A imagem `arquitetura-c4-planeta-terra.png` deve estar na mesma pasta.

## Mapeamento

| Elemento da metáfora | Conceito técnico |
|---|---|
| Núcleo Interno Sólido | Código |
| Núcleo Externo Líquido | Componentes |
| Manto Inferior Pastoso | Containers |
| Manto Superior Rígido | Sistemas |
| Crosta Terrestre | Contexto |
| Troposfera | APIs |
| Estratosfera | Mensageria |
| Mesosfera | Gateway |
| Órbita Terrestre | Infraestrutura |
| Sistema Solar | Observabilidade |
| Lua e Satélites | Serviços Externos |
| Estrelas Distantes | Usuários |
